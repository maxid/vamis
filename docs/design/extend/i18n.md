# 国际化设计

> 状态：**进行中 15%** · Amis 核对：双通道与替换契约；运行时未接 · 对应站点：`/extend/i18n` · 源码：[website/src/extend/i18n.md](../../../website/src/extend/i18n.md)

## 0. 设计结论

国际化当前**没有实现**：无 i18n 包、无 locale 注入，组件内置文案与 schema 文案都走原文。文档只能写契约与缺口，不能把 Amis 用法当 Vamis 已交付。

## 1. 边界与优先级

1. **双通道**：组件内置文案（日期面板等）与作者 schema 文案分开。
2. **locale**：`vamis.embed(..., { locale })` 是目标契约；当前未注入。
3. **replaceText**：运行期替换表是目标；当前未实现。
4. **回退**：缺失 key 回原文，不显示 key。
5. **不引入**：不加载 Amis i18n 包，不复制 locale 文件。
6. **文档诚实**：所有示例标“契约/未实现”。

## 2. 内容契约

- 首段直接声明当前未实现，避免作者误用。
- 组件内置文案与 schema 文案分两节。
- locale 注入示例标伪代码/目标 API。
- 给缺失 key/未注入 locale 的回退行为。
- 不承诺 RTL/日期格式全量。

## 3. 实现

- [SDK embed](../../../packages/vamis-sdk/src)：目标 locale 入口（未接）。
- [env](../../../packages/vamis-core/src/env.ts)：宿主环境/文案能力。
- [日期组件](../../../packages/vamis/src/renderers/form/InputDate.vue)：内置文案来源。

## 4. 缺口

- 无 i18n 包、无 locale 注入、无 replaceText。
- 内置文案未抽 key。
