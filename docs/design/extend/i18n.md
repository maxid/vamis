# 国际化设计

> 状态：**进行中 85%** · Amis 核对：locale / replaceText / schema 覆盖 / registerLocale 四条主路径已落地 · 对应站点：`/extend/i18n` · 源码：[website/src/extend/i18n.md](../../../website/src/extend/i18n.md)

## 0. 设计结论

国际化由 core 的语言包注册表和纯 schema 变换实现，Vue `VamisRoot` 与 JS SDK `vamis.embed` 共用同一内核。默认语言为 `zh-CN`，内置 `en-US` 主路径文案；不引入 Amis 语言包文件或 React locale HOC。

## 1. 契约与顺序

1. `props.locale` 决定内置文案与 schema 覆盖语言；支持 Amis 的 `en` / `zh` / `cn` 别名和下划线归一化。
2. `applySchemaLocale` 递归合并 `{ 'en-US': { label: 'Username' } }`，可覆盖任意字段，不修改原始 schema。
3. `replaceSchemaText` 在语言覆盖之后递归替换字符串，默认排除 `type/name/mode/target/reload/persistData`。
4. `schemaApi` 返回的 schema 使用同样的语言覆盖与文本替换顺序。
5. 内置文案经 `makeTranslator(locale)` 查询：当前语言 → 默认语言 → 中文 → 原 key。
6. `registerLocale` / `extendLocale` 合并语言包；`removeLocaleData` 删除 key；`setDefaultLocale` 改全局回退语言。
7. 翻译文案使用 `{{variable}}` 插值，校验文案仍兼容 `$1` 等位置参数。

## 2. 入口与动态更新

- Vue：`VamisRoot` / `VamisApp` 接收 `locale` 与可选 `translate`。
- SDK：`EmbedProps.locale`，并暴露 `registerLocale` / `extendLocale` / `removeLocaleData` / `makeTranslator` / 默认语言 API。
- `updateProps({ locale })` 和 `updateSchema(schema, { locale })` 不重挂 Vue app；根 schema、内置按钮、placeholder、校验等按新语言重算。
- `env.replaceText` / `replaceTextIgnoreKeys` 是宿主配置，不是 schema 字段。

## 3. 实现落点

- [locale.ts](../../../packages/vamis-core/src/locale.ts)：注册表、内置 zh-CN / en-US、翻译回退与插值。
- [schema-locale.ts](../../../packages/vamis-core/src/utils/schema-locale.ts)：纯递归变换、替换黑名单、源对象不变。
- [VamisRoot.vue](../../../packages/vamis-core/src/VamisRoot.vue)：当前 locale、schema 变换、响应式 env。
- [validate.ts](../../../packages/vamis-core/src/validate.ts)：校验消息走当前翻译器。
- [SDK embed](../../../packages/vamis-sdk/src/embed.ts)：locale 状态与动态更新。
- [SDK 入口](../../../packages/vamis-sdk/src/index.ts)：全局语言包 API。
- 表单、选择器、日期和分页主路径已接 `env.translate`。

## 4. 测试与验收

- core `i18n.test.ts`：别名、注册/扩展/删除、回退、插值、嵌套覆盖、源对象不变、替换黑名单、英文校验。
- SDK `i18n.test.ts`：真实 embed 的英文内置文案、运行中切回中文、覆盖后替换、日语扩展与中文回退。
- 文档活示例：`VAMIS_HOST` 替换；locale schema 覆盖与 Amis 同章节。
- 收工执行全量 `pnpm test`、`pnpm typecheck`、SDK 构建与文档对照，并双站核对 `/docs/extend/i18n` 和 `/zh-CN/docs/extend/i18n`。

## 5. 剩余缺口

- 其他渲染器仍有硬编码中文，内置英文尚未逐组件抽全。
- 日期移动滚轮的单位、所有快捷选项与完整 dayjs 区域格式化未统一收口。
- RTL 不在本轮范围。
- 语言包注册是宿主全局注册表；已挂载实例不会因为单独调用 `registerLocale` 自动重渲，需更新 locale 或 schema 触发。
