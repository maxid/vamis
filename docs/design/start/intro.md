## 0. 设计结论

首页介绍用**一张 CRUD 活示例**建立“这是运行时，不是静态文档”的第一印象；同时给出定位、作者态与能力边界。设计目标是 10 秒内看懂，不堆功能清单。

## 1. 边界与优先级

1. **一句话定位**：Vue 3 复刻 Amis 的 JSON 低代码运行时。
2. **首屏示例**：CRUD 必须有数据、筛选、排序、批量、删除。
3. **作者态**：YAML/JSON 并列；IR 只作进阶。
4. **能力边界**：不搬 cxd/主题 SCSS；不承诺 amis-editor 全功能。
5. **失败态**：mock 接口失败时页面仍可读。

## 2. 内容契约

- 首屏示例高度受控，移动端不溢出。
- 文案不出现 Amis 自称/假主机。
- 给下一步入口：快速开始 / JS SDK / 组件。
- 与 getting-started 互链。
