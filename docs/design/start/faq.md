# FAQ 设计

> 状态：**已完成 90%** · 对应站点：`/start/faq` · 源码：[website/src/start/faq.md](../../../website/src/start/faq.md)

## 0. 设计结论

FAQ 是**排障索引**：每条先给可执行结论，再给原因/链接。覆盖环境、渲染、请求、样式、迁移五类；不写成长篇教程。

## 1. 边界与优先级

1. **先结论**：每条第一句可执行。
2. **分类**：环境/渲染/请求/样式/迁移；标签可搜索。
3. **可复现**：附最小 schema/命令/错误文本。
4. **不猜**：未确认原因标“待查”，不编版本/平台差异。
5. **互链**：深入内容链到 concepts/types/start 页。
6. **品牌**：Mock 域名/错误文案用 Vamis。

## 2. 内容契约

- 每条含“现象/原因/处理/相关”四段。
- 至少覆盖：裸样式、未知 type、404/CORS、YAML 缩进、迁移差异。
- 代码块可复制；错误文本用引用块。
- 与 getting-started/sdk 互链。

## 3. 实现

- [FAQ 源](../../../website/src/start/faq.md)：内容真源。
- [pages.ts](../../../playground/src/docs/pages.ts)：路由加载。

## 4. 缺口

- 版本/平台差异未集中。
