# 多语言

::: info 实现进度 85% · 进行中
`locale`、语言包注册、全局文本替换和 schema 按语言覆盖已接入 Vue 与 JS SDK；内置英文已覆盖表单、校验、选择器、日期和分页主路径，其余组件文案与 RTL 仍待逐项补齐。
:::

Vamis 的多语言支持与 Amis 一样分为两部分：

1. 内置组件文案，例如表单按钮、校验信息、日期选择器和分页。
2. JSON / YAML schema 中的作者文案，例如 `label`、`title` 和 `tpl`。

## 内置组件多语言

SDK 内置 `zh-CN` 和 `en-US`。通过 `props.locale` 设置语言，不需要另引语言包：

```javascript
const scoped = vamis.embed(
  '#root',
  {
    type: 'page',
    title: '表单页面',
    body: {
      type: 'form',
      mode: 'horizontal',
      api: '/saveForm',
      body: [
        { label: 'Name', type: 'input-text', name: 'name' },
        { label: 'Birthday', type: 'input-date', name: 'birthday' },
      ],
    },
  },
  { locale: 'en-US' },
)
```

此时默认表单标题、提交按钮、日期 placeholder 和校验错误会显示英文。`en` 是 `en-US` 的别名，`zh` / `cn` 是 `zh-CN` 的别名，下划线写法如 `de_DE` 会归一为 `de-DE`。

Vue 入口使用同一个内核，在 `VamisRoot` 上设置 `locale`：

```vue
<template>
  <VamisRoot :schema="schema" locale="en-US" />
</template>
```

SDK 可以在不重挂应用的情况下切换语言；schema 中按语言覆盖的字段也会一起重算：

```javascript
scoped.updateProps({ locale: 'zh-CN' })
scoped.updateProps({ locale: 'en-US' })
```

未翻译的内置 key 先回退到默认语言，再回退到中文，最后保留原 key。默认语言可用 `setDefaultLocale('en-US')` 修改。

## 全局文本替换

`env.replaceText` 可以递归替换 schema 中的字符串，常用于统一替换 URL 或业务文案：

```javascript
const scoped = vamis.embed(
  '#root',
  schema,
  {},
  {
    replaceText: {
      VAMIS_HOST: 'https://maxid.github.io/vamis/',
    },
  },
)
```

下面的 `VAMIS_HOST` 会显示为替换后的地址：

```schema
{
  "type": "tpl",
  "tpl": "VAMIS_HOST"
}
```

替换默认跳过 `type`、`name`、`mode`、`target`、`reload`、`persistData`，避免破坏组件语义。可以通过 `replaceTextIgnoreKeys` 增加其他排除字段，或传函数按字段和值判断：

```javascript
vamis.embed('#root', schema, {}, {
  replaceText: { VAMIS_HOST: 'https://maxid.github.io/vamis/' },
  replaceTextIgnoreKeys: ['id', 'componentId'],
})
```

文本替换发生在 locale 字段覆盖之后。替换表按 key 长度从长到短匹配，避免短 key 抢先替换长 key 的一部分。

## schema 按语言覆盖字段

任意 schema 对象都可以放一个以 locale 为 key 的对象，用来覆盖该语言下的字段。下面的表单项在 `en-US` 下显示 `username:`，其它语言仍显示 `姓名：`：

```schema
{
  "type": "form",
  "body": [{
    "type": "input-text",
    "name": "name",
    "label": "姓名：",
    "en-US": {
      "label": "username: "
    }
  }]
}
```

覆盖不限于文案，也可以覆盖 `type` 等其他字段；嵌套 `body`、`options` 和 `schemaApi` 返回的 schema 都会递归处理。已应用的 locale 对象会从渲染副本中移除，不会修改宿主传入的原始 schema。

## 扩展内置组件语言

JS SDK 和 Vue 包都暴露 `registerLocale`。下面注册日语提交按钮，未提供的 `Form.title` 等 key 仍按回退链处理：

```javascript
vamis.registerLocale('ja-JP', {
  'Form.submit': '送信',
})

const scoped = vamis.embed('#root', schema, { locale: 'ja-JP' })
```

Vue 工程从 `vamis` 或 `@vamis/core` 引入同一组 API：

```typescript
import {
  registerLocale,
  extendLocale,
  removeLocaleData,
  makeTranslator,
  setDefaultLocale,
} from 'vamis'

registerLocale('ja-JP', { 'Form.submit': '送信' })
const translate = makeTranslator('ja-JP')
translate('Form.submit') // 送信
```

`registerLocale` 和 `extendLocale` 默认合并并覆盖同名字段；`extendLocale(name, config, false)` 保留已有同名字段。翻译文案支持 `{{variable}}` 插值，例如 `Pagination.totalCount` 的 `共 {{total}} 条`。

## 当前边界

- 内置 `en-US` 先覆盖文档主路径，不代表每个组件的所有硬编码文案都已完成抽取。
- 作者写在 schema 中的普通中文不会被自动机器翻译；请使用 locale 覆盖或 `replaceText`。
- RTL 布局和所有语言的日期区域格式化不在本次交付范围内。
