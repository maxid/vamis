# 国际化

::: danger 实现进度 15% · 进行中
没有 i18n 包。文案写在 schema（`label` / `title` / `body`）。locale / `replaceText` 仍是 D12 余项。
:::

内部组件文案（日期面板「月」「周」）和作者写在 schema 里的 `label` 是两条通道。Vamis 目前都走 schema 原文；`locale: en-US` 尚未注入 `vamis.embed`。

Amis 对多语言的支持有两方面：

1. 内部组件的多语言，比如日期组件中的日期
1. JSON 配置中的多语言，比如配置中的 label 值

## 内部组件多语言

分为 JS SDK 和 React 两种用法。

### JS SDK

Amis JS SDK 可在 embed props 里设 `locale`。Vamis 尚未注入 locale，下面按契约列出。

```javascript
const scoped = vamis.embed(
  '#root',
  {
    type: 'page',
    title: '表单页面',
    body: {
      type: 'form',
      mode: 'horizontal',
      api: '/saveForm',
      body: [
        {
          label: 'Name',
          type: 'input-text',
          name: 'name'
        }
      ]
    }
  },
  {
    locale: 'en-US'
  }
);
```

如果是其它语言，比如目前德语，需要单独引入文件

```
<script src="sdk.js"></script>
<script src="locale/de-DE.js"></script>
<script type="text/javascript">
  (function () {
    let amis = window.vamis;
    // 通过替换下面这个配置来生成不同页面
    let amisJSON = {
      type: 'page',
      body: {
        type: 'form',
        mode: 'horizontal',
        api: '/saveForm',
        body: [
          {
            label: 'Name',
            type: 'input-text',
            name: 'name'
          },
          {
            label: 'Email',
            type: 'input-email',
            name: 'email'
          }
        ]
      }
    };
    const scoped = vamis.embed('#root', amisJSON, {
      locale: 'de-DE'
    });
  })();
</script>
```

### React

Vamis 没有 React 包，内部文案走 `env` / locale，不要抄 Amis `LocaleContext`。

## 全局文本替换

`env.replaceText` 可以对 schema 里的文案做全局替换，也能拿来做简单多语言。Vamis **尚未接**。

```javascript
// sdk 中的写法
const scoped = vamis.embed(
  '#root',
  amisJSON,
  {
    // 这是 props
  },
  {
    replaceText: {
      VAMIS_HOST: 'https://maxid.github.io/vamis/'
    }
  }
);
```

比如下面的例子会对 `VAMIS_HOST` 进行替换。

```schema: scope="body"
{
  "type": "tpl",
  "tpl": "VAMIS_HOST"
}
```

这个配置会对配置中的绝大部分字段进行替换，除了 `type, name, mode, target, reload` 这几个有特殊功能的字段。

可以通过配置 `replaceTextIgnoreKeys` 属性来进行修改，让其它字段也避免被替换。

## JSON 配置中设置多语言

在 JSON 配置中，也可以设置不同语言下的不同展现，比如前面设置了 `locale` 为 `en-US`，这时在任意 JSON 配置中都能使用 `en-US` 对象来覆盖这个语言下的效果，用于实现简单的替换效果。

```schema: scope="body"
{
  "type": "form",
  "body": [
    {
      "type": "input-text",
      "name": "name",
      "label": "姓名：",
      "en-US": {
        "label": "username: "
      }
    }
  ]
}
```

请点击上方的切换语言下拉框切换到英文，就能看到 `label` 属性被替换了，除了 `label` 以外，还可以覆盖其他任意属性，比如将 type 换成其他。

## 扩展内置组件的语言

如果想扩展其他语言，首先参考 ` 文件，然后参考后面的示例注册新语言，未翻译的文字都将使用中文。

### JS SDK 扩展方法

```javascript
let amisLib = amisRequire('amis');
amisLib.registerLocale('jp', {
  'Form.submit': '送信'
});
```

### React 扩展方法

```javascript
import {registerLocale} from 'amis';
registerLocale('jp', {
  'Form.submit': '送信'
});
```
